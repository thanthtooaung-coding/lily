You are a senior frontend engineer and product designer.

Build the complete frontend for a hackathon project called:

# LILY
## AI Incident Response & Automation Platform

Lily is an AI-powered incident management platform.

The frontend communicates with a Python FastAPI backend.

The backend communicates with:
- PostgreSQL
- AI/LLM services
- n8n automation workflows

n8n is responsible for workflow automation such as:
- notifications
- Telegram alerts
- approval workflows
- automated backend actions
- incident escalation

The frontend must NOT directly communicate with n8n for core business operations.

Architecture:

React Frontend
      |
      | REST API
      ▼
FastAPI Backend
      |
      ├── PostgreSQL
      ├── AI Engine
      └── n8n
            |
            ├── Telegram
            ├── Notifications
            ├── Approvals
            └── Automated Actions

28. N8N AUTOMATION
==================================================

The frontend does NOT execute n8n directly.

FastAPI handles automation requests.

Example:

Frontend

POST /incidents/{id}/approve

FastAPI:

1. updates incident
2. creates action
3. calls n8n webhook

n8n:

1. receives webhook
2. performs automation
3. sends Telegram notification
4. calls FastAPI callback

FastAPI:

updates action status

Frontend:

TanStack Query refreshes data.

52. IMPORTANT IMPLEMENTATION RULE
==================================================

Before writing code:

1. Inspect the existing repository.

2. Do NOT delete existing working code.

3. Reuse existing configuration where appropriate.

4. Identify whether Tailwind/Vite/React are already configured.

5. Only add dependencies that are actually needed.

6. Build incrementally.

7. Keep the application runnable after every major step.

8. Do not create fake backend logic inside components.

9. Keep API logic inside src/api.

10. Keep server state inside TanStack Query.

11. Keep UI state local unless global state is genuinely required.
